# Pikera Uri Eco Lodge

Sitio web de Pikera Uri Eco Lodge (Hanga Roa, Rapa Nui).

Actualmente el sitio en producción (pikerauri.com) corre en Cloudbeds Website
Builder. Este repo es la base para un rediseño estático (HTML/CSS), siguiendo
el mismo enfoque usado en [te-moai-sunset](https://github.com/dela1305/te-moai-sunset).

- `index.html` — página principal (por crear)
